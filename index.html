      Method and data notes

      MODIS (1 km) and VIIRS (375 m) detections from NASA FIRMS are gridded to monthly counts. The harmonization stage standardizes Fire Radiative Power, corrects scan-angle distortion and diurnal overpass differences, and back-casts VIIRS-equivalent counts for 2001 to 2011, so the sensor of origin no longer drives the signal.

      The baseline is the median of each calendar month across the full record. Anomaly is the percentage difference from that median. Color ramps are colorblind-safe: a light-to-dark sequential ramp for counts and blue-to-orange for anomalies.

      Until real data loads, the page shows a synthetic dataset for demonstration. Hosted with pyroscale_data.json beside it, the page loads that file every time it opens, so the data stays as current as the last run of update_pyroscale_data.py. The loader in the Period and view panel is a manual alternative.

          Scenario lab

          Move the levers, then run the scenario to see the Earth in that future. The starting point is the machine-learning forecast for the next 24 months, then each cell’s recent level and trend. The levers are an illustrative sensitivity model with assumptions you can edit, not a forecast.

          Assumptions

          These are placeholders for illustration, not measured values. Replace them with figures from studies you trust. Where the ML forecast has no edge over the seasonal pattern, the current path falls back to each cell’s last five full years, extended by its own 10-year trend.

          With no lever moved, it shows the current path: the ML-informed baseline. Move a lever to see what a change would do.
